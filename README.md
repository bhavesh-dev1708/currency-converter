# Currency Converter

A responsive currency converter web application that converts one currency into another using real-time exchange rate data.

## Features
- Real-time currency conversion
- Dynamic country flag updates
- Currency selection dropdowns
- Responsive UI

## Concepts Used
- DOM Manipulation
- Event Listeners
- JavaScript Functions
- Objects & Arrays
- Fetch API
- Async/Await
- JSON Data Handling
- Dynamic UI Updates

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
